# 数据目录

`data/year-links/YYYY.json` 是人工维护的年度来源入口。下载清单、哈希、规范数据、索引和报告均由转换流程生成，不是额外的配置源。

| 目录 | 内容 | 规范文件 | 原始来源 |
| --- | --- | --- | --- |
| `专业对照/` | 专科专业到本科专业及考试科目映射 | `专业对照_<年份>.json` | `原始PDF/` |
| `省控线/` | 专业年度录取控制分数线 | `省控线_<年份>.json` | `原始PDF/省控线_<年份>.pdf` |
| `招生计划/` | 招生院校、专业和计划记录 | `招生计划_<年份>.json` | `原始PDF/招生计划_<年份>.pdf` |
| `招生高校及专业/` | 招生总表，用于补充计划缺失信息 | `招生高校及专业_<年份>.json` | `原始PDF/招生高校及专业_<年份>.pdf` |
| `一分一段/` | 年度索引和按专业代号存储的分片 | `一分一段_<年份>.json`、`<年份>/<代号>.json` | `原始PDF/<年份>/` |
| `来源清单/` | 官方页面、下载地址、哈希和采集状态 | `来源清单_<年份>.json` | 不适用 |
| `reports/` | 仅在有待审异常时保存核对报告；转换异常报告只在发布前暂存 | `异常数据_<年份>.json` | 不适用 |
| `schemas/` | 数据结构契约 | `*.schema.json` | 不适用 |
| `generated/` | 由规范数据生成的分析索引 | 按年度和输入摘要版本化 | 不适用 |

## 存储与权威口径

- 一分一段数据只保留年度索引和专业分片。OCR、归一化、人工确认和重试更新同一套规范文件；`needs-review` 保留在分片中，不进入网页数据。
- 已发布年度的转换计数和官方例外依据集中在 `metadata/school-data.json` 的 `conversionReports`；成功发布后不保留空报告或暂存的转换报告。
- 分数段本段人数由相邻累计人数计算，不另存重复数据。`generated/` 中的 analytics 仅用于查询和分析加速；只保留当前 catalog 引用的版本，重新生成后未引用的旧哈希快照可清理，历史版本可从 Git 记录恢复。
- 专业信息以专业对照表为准，省控线以录取控制分数线为准，院校和计划以招生计划为准，一分一段数据以对应官方表为准。
- 招生高校及专业总表只补充详细计划缺失的信息。来源冲突应进入报告，不静默覆盖。
- 总表的所有原列逐行保留在院校详情；先由专业对照确定本科专业代码，再按该代码及学校名称关联计划与总表。总表列筛选由 `metadata/school-data.template.json` 的字段 `sourceRole: colleges`、`sourceColumn` 集中声明；空白表示「未标注」，不是「否」。缺少总表的年度不能凭专业名称推断标记。退役大学生士兵免试招生计划属于另一张官方表，在独立采集和校验前不把普通计划专业标成可报。
- 2026 年已找到官方《[退役大学生士兵免试专升本招生计划](https://xcoss.henan.gov.cn/typtfile/20260408/5f9c7888935f408392a08890a893ef08.pdf)》。该表尚未进入本仓库规范数据和 catalog；后续须作为独立来源与普通、建档立卡计划区分。
- 招生计划中未能读取的学制、学费和住宿费保存为 `null`，页面显示「—」，不会把缺失项补成零。已发布计划但未单列的总表院校仍可显示，人数标记为「招生计划未单列」。
- 2024、2025 暂借用 2026 专业对照；该例外在 `metadata/school-data.template.json` 中显式声明，新年度应使用本年度对照。

## 建档立卡专项与院校代码

招生计划 PDF 中的“专升本只招建档立卡贫困家庭考生”标注属于该条招生计划。提取时从院校名称中去掉括注，同时在记录中保留院校代号，并写入 `建档立卡: "是"`、`招生类别: "建档立卡专项"`。普通计划对应 `建档立卡: "否"`。

同名院校可能使用不同招生代码分别发布普通计划和专项计划。年度分析摘要及查询结果按“院校代号＋院校名称”区分招生选项；缺少院校代号时回退到名称。查询和历年概览中的院校数按这一口径计数。筛选“建档立卡=否”只排除专项代码及其计划；如果同名院校另有普通代码，该院校仍会显示，院校卡片上的代码用于区分。筛选“是”或“全部”时，普通计划与专项计划均纳入。

筛选项标签、可选值与总表列映射集中在 `metadata/school-data.template.json`，普通与建档立卡计划的筛选语义集中在 `js/plan-filter.js`。查询列表、院校详情和统计分析共用这些口径。

例如，2026 年金融学的河南财经政法大学有普通代码 `6081`（29 人）和专项代码 `6469`（1 人）。选择“否”后只显示 `6081` 的普通计划。

新增年度、校验、人工复核和发布步骤见 [转换与导入指南](../convert/README.md)；异常报告字段和修正格式见 [异常数据复核说明](reports/README.md)。
