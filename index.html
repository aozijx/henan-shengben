数据说明

数据内容

  • 专业对照：《最新 年河南省普通高校专升本考试招生专业对照及考试科目一览表》——专科专业可报考的本科专业与专业基础考试课程。
  • 填报代号：河南省教育考试院《最新 年普通高等学校专升本考试招生专业与考试科目对照表》中的专业代号与考试科目代号。
  • 控制分数线：已配置年份 年《河南省普通高校专升本招生录取控制分数线》，按专业代号与名称双口径匹配。
  • 招生院校：《河南省 最新 年普通高职（专科）毕业生进入本科阶段学习招生高校及专业总表》，含学制、师范 / 艺术标记与就读地点备注。
  • 招生计划：已配置年份 年《河南省普通高等学校专科毕业生升入本科阶段学习招生计划》结构化数据，含计划人数、学制、学费、住宿费、通信地址、咨询电话、招生章程网址，以及原文标注的办学性质（公办 / 民办）与建档立卡专项。

院校明细字段口径

  • 办学性质：直接取自招生计划原文院校名称标注——标注「(民办)」为民办（含独立学院），未标注为公办。
  • 招生类别 / 建档立卡：原文标注「只招建档立卡贫困家庭考生」的条目列为建档立卡专项，其余为普通专升本；同一院校同一专业的普通计划与建档立卡专项为两条独立条目。
  • 计划人数 / 学费 / 住宿费 / 通信地址 / 咨询电话 / 章程网址：全部按招生计划原文逐条转录，未列项目以「—」表示；「其他说明」含办学地点等就读信息。
  • 个别专业没有院校单列招生计划，其院校明细显示「未单列」。

读取规则

  • 分数线优先按「填报代号」精确匹配；未命中再按「专业名称」精确匹配；仍未命中按名称包含匹配（处理年度表中「含 xxx」合并命名）。
  • 招生院校按年份分别取自对应年度《招生计划》（专业名称 → 填报代号，含财务管理 99 ↔ A1 差异处理）；无计划数据时回退到 metadata 声明的招生总表。同一院校同一专业的普通计划与建档立卡专项为两条独立条目。
  • 年份折叠中「公办 X 所 / 民办 Y 所」按院校名称去重统计；「计划 Z 人」为该年公办 / 民办各院校计划人数合计（含建档立卡专项）。
  • 「—」表示当年控制线表中未单列该专业或未招生，不代表 0 分，也不代表不能报考；最终以当年官方招生计划与文件为准。
