# 河南专升本 · 专业对照与分数线查询工具

按专科专业查询可报考的本科专业、考试科目、近三年（2024–2026）录取控制分数线与三年招生院校（专业行 → 年份分组 → 院校条目三级折叠，公办 / 民办分别列出，含全部字段），并提供字段可自定义的汇总表。

## 使用

在网站目录启动本地服务后，用浏览器打开：

```bash
python -m http.server 8000
# 访问 http://localhost:8000/
```

数据通过相对路径从 `data/` 目录读取，请保持目录结构完整。

运行自动化测试：

```bash
npm test
```

## 功能

- **专业查询**：输入专科专业（支持模糊匹配与候选提示），列出全部可报本科专业：填报代号、公共课（英语/专业英语）、专业基础课、2024 / 2025 / 2026 控制线、较 2025 年变化；「招生院校」按钮显示 2026 年公办/民办院校数（如 2026年 2/1 所），悬停可查看说明。
- **三级折叠（专业行 → 年份 → 院校）**：分数线表每一行为整行可点击，点击后在该专业行下方展开「年份折叠」——2024 / 2025 / 2026 三年分组，每组 summary 直接显示该年公办 X 所 / 民办 Y 所 / 计划 Z 人，便于与分数线上下对照；点击年份组再展开该年院校条目（年份分组默认全部收起）。每个院校条目可再折叠，展开显示该条目的全部字段（院校代码、专业代号、学制、计划人数、学费标准、最低住宿费、办学性质、招生类别、通信地址、其他说明、咨询电话、招生章程网址）；民办院校标注「民办」、建档立卡专项条目标注「建档立卡专项」。支持「全部展开 / 全部收起」。
- **筛选与排序**：公办/民办、建档立卡、专业基础课、院校数(2026)下限（只保留 2026 年院校数大于输入值的专业）按“且”关系生效；筛选实时作用于上方查询结果表（标题旁显示「筛选后 X / Y 个专业」）。导出预览支持点击表头排序（首次点击从高到低，再次点击从低到高，表头显示 ▲/▼ 指示），可排序列和默认排序由元数据提供；「重置筛选」恢复默认排序。
- **导出预览**：查询结果按“原始数据 → 筛选 → 排序 → 预览 → 导出”处理。预览表并列展示 2024 / 2025 / 2026 三年的分数线、院校数与计划人数（均按公办/民办拆分，以「公/民」显示，如 2/1、25/30；某年无数据显示「—」），顶部「有效院校（2026）」按最新年份筛选结果统计；表格支持分页、列宽调整与小屏横向滚动；CSV 必须直接使用完整预览结果集，因此列、值和顺序与预览一致。
- **数据分析**：近三年控制线区间分布、2026 年控制线 TOP 15、八个常见专业三年走势（ECharts 渲染；图表库不可用时自动降级为表格），并展示 2026 招生计划概览（院校数、公办 / 民办、建档立卡专项、计划招生人数）。
- **配色主题**：浅色 / 深色 / 跟随系统三态，图表配色随主题自动联动。
- **数据说明**：收录范围、读取规则与免责声明。

## 读取规则

1. 分数线优先按「填报代号」精确匹配；未命中再按「专业名称」精确匹配；仍未命中按名称包含匹配（处理年度表中「含 xxx」的合并命名）。
2. 招生院校明细优先取自《招生计划》：按本科专业名称精确匹配，未命中按填报代号匹配（含财务管理代号 99 / A1 差异处理）；仍无计划数据时回退到招生总表（6 位专业代码、忽略 T / K 后缀差异）。同一院校同一专业的普通计划与建档立卡专项为两条独立条目。
3. 办学性质（公办 / 民办）与建档立卡专项标注直接取自招生计划原文院校名称（「(民办)」「只招建档立卡贫困家庭考生」），未标注者为公办。
4. 「—」表示当年控制线表中未单列该专业或未招生，不代表 0 分，也不代表不能报考；最终以当年官方招生计划与文件为准。

## 数据来源与转换说明

数据来自河南省教育厅、河南省教育考试院公开文件：

1. 《河南省 2026 年普通高职（专科）毕业生进入本科阶段学习招生高校及专业总表》（附件 1）
2. 《2026 年河南省普通高校专升本考试招生专业对照及考试科目一览表》（附件 2，即本专科专业对照及考试课程一览表）
3. 河南省教育考试院《河南省 2026 年普通高等学校专升本考试招生专业与考试科目对照表》（专业代号、考试科目代号）
4. 河南省教育考试院公布的 2024 / 2025 / 2026 年《河南省普通高校专升本招生录取控制分数线》
5. 河南省教育考试院公布的 2024 / 2025 / 2026 年《河南省普通高等学校专科毕业生升入本科阶段学习招生计划》（全量解析：2024 年 1111 条、2025 年 1066 条、2026 年 1259 条）

以上 PDF 均以表格抽取方式转换为 `data/<数据类型>/*.json`，转换脚本与原文逐条核验：

- 2024 / 2025 年分数线 JSON 与已提供版本逐条一致；
- 2026 年分数线以 PDF 为准完整重建（原 JSON 仅含 98 条，PDF 共 185 条）；
- 「物联网应用技术」映射与预置对照文件核对一致（23 个可报本科专业，仅职教本科专业命名差异）；
- 招生计划 2026 年 46 所院校与招生总表双向一致；填报代号 186 个与对照表完全对应（仅财务管理 99 ↔ A1 命名差异）；建档立卡专项条目 280 条，计划人数无缺失；民办院校清单与院校代码核验一致（含独立学院转设改名，如新乡医学院三全学院 → 豫北医学院）。

## 元数据与年度维护

`metadata/school-data.json` 是页面业务配置的唯一入口：

- `supportedYears`、`defaultYear`：可用年份与默认年份；
- `yearSources`：每年必须声明 `mappingSource`、`scoreSource`、`planSource`，可选 `collegeFallbackSource`；
- `fields`：每个字段包含 `key`、页面 `label`、`exportLabel`、`type`，并通过 `filterEnable`、`sortEnable`、`tableShow`、`exportEnable` 控制用途；枚举字段声明 `enumValues`，数值字段可声明 `min` / `max`；
- `defaultSort`、`pageSize`、`exportFormat`：默认排序、分页大小和导出格式。

新增 2027 或后续年份时，只需：

1. 把该年度分数线和招生计划 JSON 放入各自的数据类型目录；如专业对照发生变化，也放入 `data/专业对照/`；
2. 在 `supportedYears` 添加年份，并在 `yearSources` 添加对应路径；需要时调整 `defaultYear`；
3. 运行 `npm test`，确认元数据校验、加载、筛选、排序、预览和 CSV 流程通过。

无需修改 `js/` 业务逻辑。JSON 结构须保持一致：

- 分数线：`{"专业代号": "43", "专业名称": "...", "分数线": 156}`
- 对照：`{"专科专业": "...", "可报本科专业": [{"专业名称","专业代号","考试科目代码","考试科目","代码6位"}]}`
- 招生计划：`{"年度","专业代号","专业名称","计划人数","学制","学费标准","最低住宿费","院校代号","院校名称","办学性质","招生类别","建档立卡","通信地址","其他说明","咨询电话","招生章程网址"}`
- 招生总表：`{"院校代码","学校名称","专业代码","专业名称","学制","师范","艺术","备注"}`

## 本地存储与导出约束

- 禁止把原始业务数据或筛选结果写入 `localStorage`。
- 允许的键只有主题 `henan-theme`、表格列宽 `henan-table-widths-v1` 与筛选/排序状态 `henan-explorer-v1`。
- “清除本地存储”会调用完整清理，并同时恢复默认主题、筛选、排序、分页和列宽。
- 无有效预览数据时不能导出。CSV 使用 UTF-8 BOM，按 CSV 规则转义逗号、双引号和换行；文件名为 `院校数据_<年份>_<YYYYMMDD>.csv`。
