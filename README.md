# 河南专升本查询工具

按专科专业查询可报考的本科专业、考试科目、历年省控线和招生院校。页面使用原生 HTML、CSS 和 ES 模块，年度、字段与数据源由 metadata 驱动。

## 快速开始

在仓库根目录启动页面服务：

```bash
npm run dev
```

服务默认监听局域网接口的 `8765` 端口，终端会显示本机和局域网地址。手机或其他设备需连接同一局域网，并打开终端显示的局域网地址。CSS 保存后会即时热替换；HTML、JS、metadata 或数据文件保存后会自动刷新页面。服务只提供页面运行所需的 `index.html`、`css/`、`js/`、`metadata/` 和 `data/`，不会开放仓库中的其他文件。若端口已占用，可在 PowerShell 中运行 `$env:PORT=8766; npm run dev` 更换端口。

运行自动化测试：

```bash
npm test
```

## 功能

- 输入专科专业，查看匹配的本科专业及按年份分组的成绩、院校数和招生计划。
- 年份筛选按已发布的专业对照、招生高校总表和招生计划自动扩展；仅有对照与总表的年份也可选专业、查院校，未发布的分数线和计划人数会明确标注。选中三个及以上年份时，按钮简写为起止年份。
- 结果可切换卡片或表格布局；选择专业后，在下方全宽区域查看院校计划。院校年份默认最新，仅按当前选择读取完整院校明细；可手动选择其他年份或全部可用年份。
- 表格布局按年度显示「预估最低分」：将当前筛选后该本科专业各院校的普通计划人数相加，再从对应年度一分一段的最高分向下累计人数，首次达到普通计划人数的分数即为估算值。建档立卡专项名额单列，不并入普通计划估算。缺少计划或一分一段、累计人数未覆盖计划人数时显示「—」。这是按人数静态推算的参考值，不代表院校实际录取线或录取承诺。
- 顶部数据规模按来源标注年份：专科与本科专业数取当前查询对照表，控制线、招生院校与计划条目数取最新已发布的完整招生年度。
- 年份和筛选条件同时作用于结果、数据分析与 CSV 导出；导出字段可单独勾选。
- 「师范标记」「艺术标记」从 metadata 的 `sourceRole`、`sourceColumn` 配置读取对应年度招生高校及专业总表原列；空白可选「未标注」，不会从专业名称推断。先由专业对照确定本科专业代码，再按该代码及学校名称关联计划与总表；对不上时分别展示。退役大学生士兵免试计划是独立官方表，尚未纳入本仓库规范数据，因此页面暂不声称哪些专业可报。
- 数据分析支持专业筛选、分页和多专业曲线；主题支持浅色、深色及跟随系统。
- 数据分析的人数仅统计已单列的年度招生计划；招生总表中未单列计划的院校仍可在查询结果查看，人数保持未公布或未单列。
- 院校和计划详情按需读取；原始数据和筛选结果不会保存到浏览器本地存储。

## 数据与维护

年度来源配置位于 `data/year-links/`，规范数据和来源清单位于 `data/`，已发布转换摘要集中在 `metadata/school-data.json`。新增年度需要先检查来源和转换结果，再发布：

```powershell
python -m convert.ingest_year --seed data/year-links/YYYY.json --check
```

若官方表格 PDF 已保存到 `data/` 约定路径，但该年尚无完整的 year-links，可先独立转换已取得的表格：

```powershell
python -m convert.extract_cli --local --year YYYY --write
python -m convert.refresh_catalog
```

前一命令只处理实际存在且输入齐全的本地 PDF，并记录输入与产物哈希；后一命令将各类来源按年份独立登记到 `sourceCatalog`。页面可立即展示专业对照和招生高校总表；完整年度统计仍需招生计划、省控线与一分一段等输入。

确认检查报告后，本地去掉 `--check` 执行发布。PR 中变更的新年度 seed 会逐个检查并暂存核验产物；合并到 `main` 后，Action 复用该 artifact、重建 catalog 并提交生成物。若 seed 已在仓库且无需改动，可在 PR 分支上手动运行 Action，指定 `data/year-links/YYYY.json`；合并后 Action 会按 PR head commit 找到并校验该次运行的 artifact。直接推送新年度 seed 到 `main` 时，Action 会针对变更年度执行完整导入；已发布年度仍不能用新年度导入入口覆盖。已有年度复核、采集、转换、异常处理和回滚步骤见 [转换与导入指南](convert/README.md)。

## 目录

- `index.html`：页面骨架和静态区块。
- `css/`：基础主题、查询、分析、导出和数据说明样式。
- `js/`：查询、筛选、结果展示、数据分析及导出模块。
- `metadata/`：页面字段、年份、数据源和筛选规则。
- `data/`：规范 JSON、官方来源清单、PDF、生成索引及审核报告。
- `crawler/`、`convert/`：官方文件采集、转换、校验和年度发布工具。
- `tests/`：Node 内置测试及数据契约校验。

## 数据来源与许可

数据由河南省教育厅、河南省教育考试院公开文件转换整理，数据口径和来源见页面「数据说明」及 [数据目录说明](data/README.md)。报考时以当年官方招生文件为准。
