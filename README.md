# 河南专升本 · 专业对照与分数线查询工具

按专科专业查询可报考的本科专业、考试科目、近三年（2024–2026）录取控制分数线与 2026 年招生院校（院校明细按专业两级折叠展示，含全部字段）。

## 使用

在网站目录启动本地服务后，用浏览器打开：

```bash
python -m http.server 8000
# 访问 http://localhost:8000/
```

数据通过相对路径从 `data/` 目录读取，请保持目录结构完整。

## 功能

- **专业查询**：输入专科专业（支持模糊匹配与候选提示），列出全部可报本科专业：填报代号、公共课（英语/专业英语）、专业基础课、2024 / 2025 / 2026 控制线、较 2025 年变化。
- **招生院校明细（按专业行展开）**：分数线表每行末列显示「院校 N 所」按钮，点击后在该专业行下方直接展开其招生院校明细，便于与分数线上下对照。明细内每个院校可再折叠，展开显示该条目全部字段（院校代码、专业代号、学制、计划人数、学费标准、最低住宿费、办学性质、招生类别、通信地址、其他说明、咨询电话、招生章程网址）；民办院校标注「民办」、建档立卡专项条目标注「建档立卡专项」；支持「全部展开 / 全部收起」。
- **数据分析**：近三年控制线区间分布、2026 年控制线 TOP 15、八个常见专业三年走势（ECharts 渲染；图表库不可用时自动降级为表格），并展示 2026 招生计划概览（院校数、公办 / 民办、建档立卡专项、计划招生人数）。
- **配色主题**：浅色 / 深色 / 跟随系统三态，图表配色随主题自动联动。
- **数据说明**：收录范围、读取规则与免责声明。

## 读取规则

1. 分数线优先按「填报代号」精确匹配；未命中再按「专业名称」精确匹配；仍未命中按名称包含匹配（处理年度表中「含 xxx」的合并命名）。
2. 招生院校明细优先取自《招生计划》：按本科专业名称精确匹配，未命中按填报代号匹配（含财务管理代号 99 / A1 差异处理）；仍无计划数据时回退到招生总表（6 位专业代码、忽略 T / K 后缀差异）。同一院校同一专业的普通计划与建档立卡专项为两条独立条目。
3. 办学性质（公办 / 民办）与建档立卡专项标注直接取自招生计划原文院校名称（「(民办)」「只招建档立卡贫困家庭考生」），未标注者为公办。
4. 「—」表示当年控制线表中未单列该专业或未招生，不代表 0 分，也不代表不能报考；最终以当年官方招生计划与文件为准。

## 数据来源与转换说明

数据来自河南省教育厅、河南省教育考试院公开文件：

1. 《河南省 2026 年普通高职（专科）毕业生进入本科阶段学习招生高校及专业总表》（附件 1）
2. 《2026 年河南省普通高校专升本考试招生专业对照及考试科目一览表》（附件 2，即本专科专业对照及考试课程一览表）
3. 河南省教育考试院《河南省 2026 年普通高等学校专升本考试招生专业与考试科目对照表》（专业代号、考试科目代号）
4. 河南省教育考试院公布的 2024 / 2025 / 2026 年《河南省普通高校专升本招生录取控制分数线》
5. 河南省教育考试院公布的 2024 / 2025 / 2026 年《河南省普通高等学校专科毕业生升入本科阶段学习招生计划》（全量解析：2024 年 1111 条、2025 年 1066 条、2026 年 1259 条）

以上 PDF 均以表格抽取方式转换为 `data/*.json`，转换脚本与原文逐条核验：

- 2024 / 2025 年分数线 JSON 与已提供版本逐条一致；
- 2026 年分数线以 PDF 为准完整重建（原 JSON 仅含 98 条，PDF 共 185 条）；
- 「物联网应用技术」映射与预置对照文件核对一致（23 个可报本科专业，仅职教本科专业命名差异）；
- 招生计划 2026 年 46 所院校与招生总表双向一致；填报代号 186 个与对照表完全对应（仅财务管理 99 ↔ A1 命名差异）；建档立卡专项条目 280 条，计划人数无缺失；民办院校清单与院校代码核验一致（含独立学院转设改名，如新乡医学院三全学院 → 豫北医学院）。

## 更新数据

- 分数线：`{"专业代号": "43", "专业名称": "...", "分数线": 156}`
- 对照：`{"专科专业": "...", "可报本科专业": [{"专业名称","专业代号","考试科目代码","考试科目","代码6位"}]}`
- 招生计划：`{"年度","专业代号","专业名称","计划人数","学制","学费标准","最低住宿费","院校代号","院校名称","办学性质","招生类别","建档立卡","通信地址","其他说明","咨询电话","招生章程网址"}`
- 招生总表：`{"院校代码","学校名称","专业代码","专业名称","学制","师范","艺术","备注"}`
