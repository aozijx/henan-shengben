# 河南专升本 · 专业对照与分数线查询工具

按专科专业查询可报考的本科专业、考试科目、metadata 配置年份（当前为 2024–2026）的省控线与招生院校；结果支持聚合卡片和历年成绩/招生表格，专业行可展开院校详情，并可勾选字段导出 CSV。

## 使用

在网站目录启动本地服务后，用浏览器打开：

```bash
python -m http.server 8000
# 访问 http://localhost:8000/
```

数据通过相对路径从 `data/` 目录读取，请保持目录结构完整。

## 数据更新（一条命令）

新增年度时，先在 `data/year-links/YYYY.json` 登记官方来源。下面这一条命令会自动解析公告页、下载 PDF、抽取表格、识别一分一段、生成分片和审计报告、校验数据并更新 catalog 与 metadata：

```powershell
python -m convert.ingest_year --seed data/year-links/YYYY.json
```

首次运行建议加 `--check` 先预览；检查模式只在暂存目录处理并输出摘要，不发布数据。默认输出简短统计和异常；需要完整来源及逐专业明细时加 `--full-report`。`--seed` 必须指向尚未发布的新年度；现有年度不能用导入入口覆盖。参数和各阶段说明见 [convert/README.md](convert/README.md)。

复核已发布年度时，不要使用 `ingest_year`。在隔离副本中运行异常复核和 catalog 校验的 PowerShell 流程，见 [已有年度复核说明](convert/README.md#已有年度复核)。

运行自动化测试：

```bash
npm test
```

## 功能

- **专业查询与聚合结果**：输入专科专业时支持候选补全；回车会将采用的完整专业名回填。结果区按 `selectedYears` 展示可报本科专业、公共课、专业基础课、省控线，以及公办/民办分别统计的普通与专项计划；展开一个本科专业后，同一院校会聚合成跨年份对比卡片，年份标记附在院校计划上，并按原始招生计划展示院校/专业代码、学制、学费、住宿费、地址、电话、备注和招生章程。
- **年份与布局**：年份入口固定在查询页筛选面板中，即使结果为空也能调整；弹窗由 `supportedYears` 动态生成，支持全选、仅最新年份和多选。布局通过紧凑的卡片/表格图标切换；专业主表展示历年成绩与招生概览，展开后在专业下方显示各院校详情。宽表仅在结果容器内横向滚动。
- **筛选与排序**：公办/民办、建档立卡、专业基础课和当前 `focusYear` 的院校数下限按“且”关系生效。筛选后再排序；可排序字段与默认排序由 metadata 提供。“重置筛选”和“清除本地存储”归入筛选区的操作组，前者恢复 metadata 默认排序。
- **院校详情入口**：聚合卡片将“查看院校详情”放在本科专业标题行右侧，逐年概览无需滚动到卡片底部即可展开；详情仍按需渲染，避免首屏加载全部院校记录。
- **CSV 导出**：导出入口与结果布局切换并列。弹窗按专业信息和年份分组展示 metadata 中启用的字段，默认全选，可清空或逐项勾选；年份集合限制可导出年度字段。CSV 按当前完整筛选专业集生成，不受表格布局、详情展开或可视分页影响；`focusYear` 是已选年份中最新的一年，用于搜索映射、有效院校统计和文件名。
- **数据分析**：继承查询页的年份、办学性质、建档立卡、专业课和院校数条件，页首可返回筛选面板调整；年度 analytics 同时驱动计划概览、控制线分布、TOP 15 与完整专业列表。完整列表提供分页，并显示公办/民办院校数和普通/专项计划。勾选多个专业后按需读取相应年份的一分一段分片，提供位次—分数、累计人数、本段人数和归一化百分比四种曲线；图表库不可用时提供文本降级。
- **配色主题**：浅色 / 深色 / 跟随系统三态，图表配色随主题自动联动。
- **数据说明**：收录范围、读取规则与免责声明。

## 读取规则

1. 分数线优先按「填报代号」精确匹配；未命中再按「专业名称」精确匹配；仍未命中按名称包含匹配（处理年度表中「含 xxx」的合并命名）。
2. 招生院校明细优先取自《招生计划》：按本科专业名称匹配（统一空格、括号和“本科层次职业教育专业”后缀）；名称未命中时，仅在该填报代号对应唯一专业名称时按代号回退（含 99 / A1 别名），避免同代码不同专业的计划被合并；仍无计划数据时回退到招生总表（6 位专业代码、忽略 T / K 后缀差异）。同一院校同一专业的普通计划与建档立卡专项为两条独立条目。
3. 办学性质（公办 / 民办）与建档立卡专项标注直接取自招生计划原文院校名称（「(民办)」「只招建档立卡贫困家庭考生」），未标注者为公办。
4. 「—」表示当年控制线表中未单列该专业或未招生，不代表 0 分，也不代表不能报考；最终以当年官方招生计划与文件为准。

## 数据来源与转换说明

数据来自河南省教育厅、河南省教育考试院公开文件：

1. 《河南省 2026 年普通高职（专科）毕业生进入本科阶段学习招生高校及专业总表》（附件 1）
2. 《2026 年河南省普通高校专升本考试招生专业对照及考试科目一览表》（附件 2，即本专科专业对照及考试课程一览表）
3. 河南省教育考试院《河南省 2026 年普通高等学校专升本考试招生专业与考试科目对照表》（专业代号、考试科目代号）
4. 河南省教育考试院公布的 2024 / 2025 / 2026 年《河南省普通高校专升本招生录取控制分数线》
5. 河南省教育考试院公布的 2024 / 2025 / 2026 年《河南省普通高等学校专科毕业生升入本科阶段学习招生计划》（全量解析：2024 年 1111 条、2025 年 1066 条、2026 年 1259 条）

以上 PDF 均以表格抽取方式转换为 `data/<数据类型>/*.json`，转换脚本与原文逐条核验：

- 2024 / 2025 年分数线 JSON 与已提供版本逐条一致；
- 2026 年分数线以 PDF 为准完整重建（原 JSON 仅含 98 条，PDF 共 185 条）；
- 「物联网应用技术」映射与预置对照文件核对一致（23 个可报本科专业，仅职教本科专业命名差异）；
- 招生计划 2026 年 46 所院校与招生总表双向一致；填报代号 186 个与对照表完全对应（仅财务管理 99 ↔ A1 命名差异）；建档立卡专项条目 280 条，计划人数无缺失；民办院校清单与院校代码核验一致（含独立学院转设改名，如新乡医学院三全学院 → 豫北医学院）。

## 元数据与年度维护

`metadata/school-data.template.json` 保存手写的页面字段、默认 UI 配置和旧年度对照借用声明；`metadata/school-data.json` 是自动生成、供页面读取的发布入口。`python -m convert.refresh_catalog` 从规范分片索引与转换报告生成年度来源字段和 v3 metadata。新增年度须先获得该年的专业对照。2024、2025 暂时使用 2026 对照，`mappingReferenceYear` 明示这个替代来源。启动仅读取 metadata 与默认查询索引；查询结果和数据分析按所选年份读取轻量 analytics，展开院校详情时才读取完整招生计划，勾选专业后直接读取规范的一分一段分片。图表所需的本段人数由相邻累计人数计算，不再保存重复专业文件。数据分析页可同时勾选多个本科专业，完整列表分页展示，TOP 图仍固定前 15。

原有说明中的年度字段配置如下：

- `supportedYears`、`defaultYear`：可用年份与默认年份；`uiDefaults` 指定默认全选策略和结果布局；
- `yearSources`：每年含 `mappingSource`、`queryIndexSource`、`scoreSource`、`planSource` 和指向规范一分一段索引/分片的 `scoreSegmentSource`、`scoreSegmentIndexSource`、`scoreSegmentShardTemplate`；`analyticsSource` 指向生成的轻量院校汇总；`collegeFallbackSource` 可选；
- `fields`：每个字段包含 `key`、页面 `label`、`exportLabel`、`type`，并通过 `filterEnable`、`sortEnable`、`tableShow`、`exportEnable` 控制用途；枚举字段声明 `enumValues`，数值字段可声明 `min` / `max`；
- `yearFieldTemplates`：按 `supportedYears` 展开省控线、院校数和计划人数列，避免为新年份手写字段；
- `resultVisibilityRules`：根据当前筛选条件隐藏结果区字段。例如建档立卡筛选为“否”时隐藏专项计划标签；院校详情同时只保留普通计划条目；
- `defaultSort`、`pageSize`、`exportFormat`：默认排序、分页大小和导出格式。

新增 2027 或后续年份时，只需：

1. 创建 `data/year-links/YYYY.json`，只登记年度、官方检索页以及已确认的公告页/附件 URL；后续年份必须有自己的专业对照，2024、2025 暂借 2026 对照不是默认策略。
2. 先运行 `python -m convert.ingest_year --seed data/year-links/YYYY.json --check` 审查来源、哈希、行数、覆盖率和 metadata diff；确认后去掉 `--check` 发布。工具在临时目录完成下载、转换、归一化和 catalog 刷新，最后一次性替换 `metadata/school-data.json`。
3. 不需要修改 JS、页面字段、`supportedYears` 或 `yearSources`；`yearFieldTemplates` 会展开新年度列，年份弹窗也会自动显示它。未在 year-links 中声明的年份不会被工具扫描或发布。
4. 运行 `npm test`，确认元数据校验、加载、筛选、排序、预览和 CSV 流程通过。

无需修改 `js/` 业务逻辑。JSON 结构须保持一致：

- 分数线：`{"专业代号": "43", "专业名称": "...", "分数线": 156}`
- 对照：`{"专科专业": "...", "可报本科专业": [{"专业名称","专业代号","考试科目代码","考试科目","代码6位"}]}`
- 招生计划：`{"年度","专业代号","专业名称","计划人数","学制","学费标准","最低住宿费","院校代号","院校名称","办学性质","招生类别","建档立卡","通信地址","其他说明","咨询电话","招生章程网址"}`
- 招生总表：`{"院校代码","学校名称","专业代码","专业名称","学制","师范","艺术","备注"}`

## 本地存储与导出约束

- 禁止把原始业务数据或筛选结果写入 `localStorage`。
- 允许的键只有主题 `henan-theme`、表格列宽 `henan-table-widths-v1` 与筛选/排序/年份选择/布局状态 `henan-explorer-v1`。
- “清除本地存储”会调用完整清理，并同时恢复默认主题、筛选、排序、年份选择、布局、分页和列宽。
- 无有效预览数据时不能导出。CSV 使用 UTF-8 BOM，按 CSV 规则转义逗号、双引号和换行；文件名为 `院校数据_<年份>_<YYYYMMDD>.csv`。
