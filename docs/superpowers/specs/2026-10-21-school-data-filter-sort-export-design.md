# 院校数据筛选排序导出改造设计

## 目标与范围

在保留现有“专科专业 → 可报本科专业”搜索、三年分数线、三年招生计划和院校明细能力的前提下，将年份、字段、筛选、排序、预览列和导出列统一交给 metadata 配置。搜索后的招生计划条目先按条件过滤，再按本科专业聚合为预览行，之后排序、分页展示并按完全相同的行与列导出 CSV。

本设计以用户提供的《School Data Filter-Sort-Export Refactor》1.2 版为需求基线，并以提交 `6cb3f19` 中的三年招生计划、三级折叠和汇总表能力为实现起点。

## 当前代码评估

- `js/data.js` 已能加载 2024–2026 分数线与招生计划，并提供按年匹配和聚合；但 `YEARS`、文件路径、默认 2026 年以及中文字段名均写死。
- `js/table.js` 已能将最近查询结果汇总为表格；但年份、指标、表头和 DOM 选择器写死，且表格位于独立页签，不满足“搜索模块最下方预览”的布局。
- `js/render.js` 已实现三层折叠院校详情，但年份顺序、列和文本写死。
- `index.html` 直接声明汇总表年份/指标控件，新增年份仍需改业务页面。
- `localStorage` 当前只保存主题，未保存业务数据；清除全部本地存储后需要重新应用默认主题和表格状态。
- 当前没有自动化测试或构建系统。所有 JavaScript 与 8 个 JSON 文件在 2026-10-21 的只读检查中通过语法/解析检查。

## 数据模型与 metadata

新增 `metadata/school-data.json`，包含：

- `schemaVersion`、`defaultYear`、`supportedYears`。
- 每个年份对应的 `mappingSource`、`scoreSource`、`planSource` 和可选 `collegeFallbackSource`。
- `fields`：每项声明稳定 `key`、页面 `label`、`exportLabel`、`type`、可选 `enumValues`/`min`/`max`，以及 `filterEnable`、`sortEnable`、`tableShow`、`exportEnable`。
- `defaultSort`、`scorePresets`、`pageSize`、`exportFormat`。

业务代码只认识稳定 key，不再按年份拼路径，也不为 2027 增加分支。元数据加载后先由纯函数 `validateMetadata(value)` 校验；错误以中文问题列表返回并在页面错误区展示，页面不继续初始化。

预览行是“当前搜索结果中每个可报本科专业在选中年份的聚合结果”。先从匹配的招生计划条目中过滤办学性质、建档立卡和分数区间；无剩余条目的专业不进入结果。每行包含专业、分数、公办/民办/总院校数、计划人数等派生字段。顶部“有效院校总数量”按过滤后招生计划中的院校名称去重，不把同校普通计划和建档立卡专项重复计算。

## 数据流水线

固定链路为：

1. metadata 指定的数据源加载为只读原始数据。
2. 专科专业搜索得到可报本科专业集合。
3. 选中年份的招生计划与分数线被规范化为统一记录。
4. 所有筛选条件以“且”关系作用于计划条目。
5. 过滤后的条目按本科专业聚合为预览行。
6. 使用稳定排序生成完整预览结果；“原始顺序”使用搜索结果中的初始序号。
7. 完整预览结果供统计、分页渲染和 CSV 导出共同消费；分页只影响 DOM，不改变导出范围。

分数输入只接受非负整数，并同时执行输入约束和纯函数校验。最低分高于最高分时不执行筛选，显示就地错误提示。快速档位只写入同一套最低/最高分状态，不产生第二条筛选路径。

## 页面与状态

搜索区保持现有入口。搜索结果之后依次渲染 metadata 驱动的基础属性筛选、分数筛选、排序、操作按钮、预览统计和分页表格，最后是导出按钮。现有独立“汇总表”页签及静态控件被移除，其聚合展示能力迁入预览组件。

状态由单一 `ExplorerState` 保存：加载状态、当前年份、搜索结果、筛选条件、排序和页码。重置筛选恢复 metadata 的默认排序与第一页，但保留当前搜索词和年份；“清除本地存储”调用 `localStorage.clear()` 后再恢复完整初始状态、默认主题和默认列宽。

仅列宽使用 `henan-table-widths-v1` 保存。主题继续使用现有 `henan-theme`。任何原始数据、索引、搜索结果、过滤结果和预览结果都不得写入 Web Storage。

## 导出与一致性

CSV 导出接收当前完整预览结果和 metadata 中 `exportEnable` 的列，表头使用 `exportLabel`。预览表格使用同一行值格式化器，确保内容语义一致；CSV 做 RFC 4180 风格的引号转义并添加 UTF-8 BOM，便于 Excel 打开中文。

文件名为 `院校数据_<年份>_<YYYYMMDD>.csv`。结果为空时导出按钮禁用；导出函数仍防御性拒绝空数组。XLSX 本期只通过 exporter 接口预留，不引入依赖或空按钮。

## 异常、性能与无障碍

- metadata、任一必需数据源或 JSON 解析失败时，退出 loading 并显示含文件名的友好错误，不留下可点击的筛选/导出按钮。
- 加载期间显示明确状态并禁用操作。
- 每页默认 50 行（由 metadata 配置）；切换筛选或排序回到第一页。
- 表格外层横向滚动；列宽拖动保留键盘可访问的默认宽度，不依赖持久化才能使用。
- 空搜索结果、过滤为空、metadata 无效是三种不同提示。

## 2027 验收

测试夹具增加 2027 年 metadata 与小型数据文件；生产业务 JavaScript 不作任何 2027 专用修改。验收证明：只把 2027 加入 `supportedYears` 并配置数据源，即可生成年份选项、筛选、排序、预览和导出文件名。

## 非目标

- 不引入前端框架、构建器或 XLSX 依赖。
- 不改变 PDF 转换流程或修订原始业务数据内容。
- 不把预览分页解释为“只导出当前页”。
- 不在本次改造中重做统计图表；只让其继续兼容 metadata 加载后的数据接口。
