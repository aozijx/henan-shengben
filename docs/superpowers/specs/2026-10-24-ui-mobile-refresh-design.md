# 河南专升本查询工具 UI 与移动端改版设计

**日期：** 2026-10-24  
**状态：** 已批准（用户 2026-10-24 回复“继续”）  
**范围：** 仅调整页面展示层级、视觉样式和响应式布局；保留现有查询与数据处理行为。

## 意图

让专业查询、数据分析和数据说明在桌面与手机上都易于扫描和操作。视觉上保持专业、克制，以黑白为主，深色页面采用 `#0f1317`、卡片和表格采用 `#171d24`；边线使用低亮度灰白，强调色保持克制。超椭圆使用浏览器支持时的渐进增强，并提供普通圆角回退。

## 目标

- 复用 `.superpowers/brainstorm` 中已选的渐进式查询工作台及结果层级：本科专业比较 → 年度汇总 → 按需展开院校明细。
- 桌面查询区采用清晰的筛选区与结果区工作台布局；窄屏改为单列，筛选区排在结果前，并确保控件易触达。
- 统一三页签、搜索、筛选、卡片、图表、表格和说明区的视觉语言与间距层级。
- 窄屏避免页面整体横向溢出；对确实需要多列的数据表保留容器内横向滚动，保证内容可读。
- 保留浅色、深色和跟随系统主题，以及键盘焦点、触控尺寸和减少动态效果设置。

## 非目标

- 不改查询语义、筛选默认值、年份选择、排序、聚合、预览、导出、统计口径或数据来源。
- 不删减现有字段、操作、分析图表或数据说明。
- 不引入前端框架、组件库或新的运行时依赖。

## 方案与决定

1. **局部美化现有纵向页面。** 改动最小，但不会充分体现旧草案中推荐的桌面查询工作台层级。
2. **沿用渐进式查询工作台，重排展示层并复用现有逻辑（选定）。** 桌面并列筛选与结果，手机纵向排列；通过专业摘要、年度汇总、院校明细逐层展开。它沿用旧草案推荐方向，同时不动数据流水线与功能契约。
3. **全面改写页面与交互。** 自由度较大，但超出本次视觉和适配目标，回归范围也不必要地扩大。

## 视觉与适配决定

- 浅色页面保持白色表面；深色主题页面使用 `#0f1317`，卡片和表格使用 `#171d24`，避免纯黑造成过强反差。
- 深色边线用低亮度灰白；蓝色标记主操作、链接和选中状态，青绿、琥珀、紫色和陶土色仅用于小面积文字与图表线条。结果布局切换器可用低饱和深蓝区分悬停、焦点与选中状态。
- 边框保留常规细线宽度。手机上结果布局切换器与筛选内容左侧对齐；桌面和手机上，导出预览都排在结果之后。
- 年份筛选按钮只显示选择值，不再重复显示上方的“年份”字段标题；辅助技术名称仍描述其年份选择用途。
- 以少量圆角层级区分页面外壳、卡片和控件；`corner-shape` / `superellipse()` 仅作为增强，`border-radius` 为兼容回退。
- 桌面查询工作台优先保证结果阅读宽度，筛选区使用稳定窄栏；筛选分组、结果工具栏和主要内容有明确标题与留白。
- 手机页签、搜索与筛选控件适配窄宽度和触控；统计摘要使用紧凑网格；院校明细纵向展开；分析图表自适应宽度。多列对照表仅在自身容器内横向滚动。
- 页面导航保持普通文档流；表头冻结只放在结果表和导出预览各自的滚动容器内。

## 验收

- 桌面宽度下，查询、筛选、结果、预览的层级清楚；不同页面的卡片与控件样式一致。
- 约 360–390 px 的手机宽度下，三个视图都无页面级横向溢出，控件不挤压，表格需要时可在局部横向滚动。
- 浅色、深色与系统主题下文字和边界保持可辨；超椭圆不支持时仍有完整圆角外观。
- 查询、筛选、排序、年份切换、卡片/表格切换、详情展开、图表与导出行为保持原样。
- 检查桌面与手机视口的实际布局；本次不新增或运行自动化测试。
