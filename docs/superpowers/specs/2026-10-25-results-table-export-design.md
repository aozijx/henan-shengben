# 查询主表与导出入口改版设计

**日期：** 2026-10-25  
**状态：** 已实施；2026-10-25 补充要求将院校详情移入结果下方独立 section
**范围：** 查询结果表格层级、院校详情、导出字段选择与查询工作区容器；不改聚合和筛选语义。

## 意图

把专业查询结果和导出预览收拢到一个主表工作区，避免同一组专业摘要上下重复展示。主表按专业展示所有选中年份的量化成绩和招生数据；学校详情移到表格/卡片结果下方的独立全宽 section，选择一个专业后在此按卡片或列表查看院校计划。导出操作放在主表上方，与卡片/表格视图切换器并排；导出前可用复选框选择字段。

## 当前实现与依据

- `js/results-view.js` 的结果视图按“本科专业 → 历年概览 → 院校详情”聚合显示。
- `js/result-model.js` 的 `projectAggregate()` 将每个专业投影为摘要行，包含专业信息、各年分数线、公民办院校数和计划人数。
- `js/preview.js` 和 `js/export.js` 基于同一批筛选后的专业摘要生成预览及 CSV 字段；两者粒度一致，但结果聚合表与导出字段表各自重复呈现了摘要。
- 院校详情来自各专业各年份的学校及计划记录，与专业量化汇总分层展示；主表点击选择专业后按需加载到全宽院校 section。
- 当前导出入口位于查询区末尾；字段集合由 metadata 的 `exportEnable` 控制，尚无用户逐次勾选界面。

## 目标

- `.result` 成为与筛选面板同一查询工作区中的卡片容器：使用 `var(--card)` 背景、`1px solid var(--line)` 边框、`var(--radius)` 圆角、高度填满网格行，并使用纵向 Flex 布局。
- `.result` 的空态在容器内水平、垂直居中；有结果时工具栏和表格占据全部可用宽度，避免 Flex 居中使表格收窄。
- 主表按专业逐行展示专业名称、考试信息，以及每个选中年份的分数线、院校数和计划人数概览；历年概览在表格中保持清晰分组。主表不加载一分一段位次，因此不渲染参考位次占位；展开后的分数段详情继续展示实际位次数据。
- 桌面表格收敛为“本科专业 / 历年成绩与招生 / 院校”三列；专业代码和考试科目并入专业单元格的次级说明。每年将省控线单独占一行，公办和民办的院校数、普通及专项计划并排，避免三项数据用双列网格时出现孤项和错位。
- 360–600px 手机视口将每行呈现为纵向专业卡片，年份摘要按双列小卡排列，并保留年度、数据和详情的明确标签；无需横向拖动宽表。
- 点击专业行的院校操作后，在筛选面板与主表所在网格行之后，显示横跨查询工作区全宽的院校 section；一次只展示一个专业，避免把所有专业院校记录堆成长页。section 支持卡片和列表切换；沿用现有学校身份合并、年份标记和筛选隐藏规则。
- 删除表格下方重复的导出预览。保留分页、排序和局部横向滚动中仍有价值的表格行为；排序/分页继续作用于整个筛选结果，不因详情展开改变导出行集。
- 将“导出 CSV”操作移到主表工具栏，紧邻卡片/表格视图切换器。
- 点击导出后打开字段选择对话框，默认勾选当前 metadata 中 `exportEnable: true` 且属于所选年份的字段；只将勾选字段写入 CSV，不改变当前表格列或筛选结果。至少勾选一个字段才允许导出。
- 查询结果、操作工具栏、院校 section 标题与布局切换器等稳定骨架写在 `index.html`；结果更新只替换状态、结果内容和选中专业的院校内容，避免每次都重建外层区域。按职责拆出导出字段选择模块。
- 年份选择继续限制主表年份概览、院校明细、导出字段及 CSV 内容；其他查询和筛选行为保持现状。
- 手机上筛选面板与结果容器具有一致的外宽和起始边缘；结果切换和导出按钮紧凑并排（不足以容纳时自然换行），不撑满整行压缩筛选布局。手机表格使用纵向卡片行；桌面只有年份数量过多时才在结果表容器内横向滚动。院校 section 是主结果之后的独立网格项，横跨查询工作区全宽；卡片模式多列排列，列表模式单列占满宽度。

## 非目标

- 不修改查询数据源、筛选默认值、专业匹配、汇总口径、CSV 编码、文件名规则或 metadata 字段定义。
- 不新增框架、组件库或依赖。
- 不把院校招生记录变成 CSV 的默认行粒度；导出继续按每个筛选后的本科专业一行，字段由用户选择。
- 不因表格显示切换而重置筛选、排序、年份或当前选中的院校专业。

## 方案

1. **统一主表工作区（用户选择）。** 主表负责专业、历年成绩和招生概况；选中专业后，在主结果行下方横跨整个查询网格的独立 section 展示院校。section 外壳、标题和布局切换器写入 HTML 静态骨架，内容按所选专业更新。移除底部预览，以主表为唯一专业摘要表；导出按钮放在顶部工具栏，并通过字段复选框对话框选择 CSV 列。
2. **保留两张表并统一对齐。** 主表继续显示专业与历年汇总，预览表继续显示导出字段，统一容器宽度和表头操作。实现风险较低，但仍重复显示相同的专业摘要，不符合收拢目标。

## 关键交互

- 卡片/表格切换保留；导出按钮固定在结果工具栏中，两个控件作为同一组内容，宽度由内容决定。
- 表格视图中每个专业是一行；卡片视图每个专业保留摘要卡片。两种视图都以“查看院校”选择专业，不在专业行内嵌套学校详情。
- 专业结果之后始终保留独立院校 section；未选择专业时显示提示，选择后加载该专业学校；一次只展示一个专业。section 骨架写在 `index.html`，仅内容按当前专业更新。卡片/列表切换只改变该 section 的排布，不重置筛选或主表布局。
- 导出字段对话框按基础字段和年份字段分组；每个字段为复选框，默认勾选当前 metadata 中可导出的字段，并提供“全选 / 清空选择”、取消和导出操作。年份过滤后的字段集作为对话框候选集。
- CSV 使用完整的当前专业结果，不受表格分页和院校选择状态影响。

## 验收

- `.result` 与筛选面板在桌面工作区同一行对齐；移动端两者外宽一致，按钮组保持紧凑，筛选字段不被按钮组挤压。
- 结果未就绪、无查询和无匹配时，提示在结果卡片内居中；查询成功后表格与工具栏铺满卡片内容宽度。
- 桌面表格的专业、年度摘要和详情入口能同时进入视野；360–390 px 手机视口下无需横向拖动即可读到所选年份。
- 各专业的逐年分数与招生汇总正确，省控线、公办和民办计划指标对齐清晰；选择专业后，横跨查询工作区全宽的院校 section 显示对应学校/年份记录，筛选可见性保持不变。
- 导出字段复选状态决定 CSV 列；取消不导出；至少勾选一项后，CSV 仍按专业一行输出完整筛选集。
- 取消底部重复预览后，原先预览区可用的分页、排序或列宽操作要么集成到主表，要么删除并说明其不再适用；不留死按钮。
- 手机表格行按专业分组，年度量化摘要不溢出；院校 section 位于主结果行下方并占满查询工作区宽度，列表模式在小屏单列显示。

## 留给实现者的决定

- 若字段太多，导出对话框可采用分组折叠；优先保证手机单列、可滚动和明确的底部操作。
- 结合现有聚合结果模型确定每年摘要的信息密度，不引入新的数据查询请求。
- “历年概览”分组标题和“学校详情”子行需明确区分，避免混淆专业级统计和学校级记录。
